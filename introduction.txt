The following data types are used frequently:
- TickType_t: 32-bit unsigned integer, which refers to system ticks;
- BaseType_t: 32-bit unsigned integer, whose use ensures efficiency on the hardware platform.
The variable names in FreeRTOS use the following prefixes:
- 'c', char type;
- 's', short type;
- 'l', long type;
- 'x', TickType_t, BaseType_t and more;
- 'v', void type.
In addition, the prefix 'u' stands for 'unsigned' (e.g: 'us' stands for 'unsigned short') and, if the variable is a pointer, the name is prefixed with 'p' (e.g: 'pc' stands for 'pointer to char').
Function names are prefixed with two components: first, the data type of the value returned, then the file the function is defined in (e.g: 'vTaskPrioritySet()' is a function defined in 'task.c' and returns a void).
In C, a macro is a substitution automatically performed in the code, even before it is compiled. 
Macros as symbolic constants (e.g: #define N 50) and parametric macros (e.g: #define squared(x) (x*x) // This will replace int surface = square(s) with int surface = s*s).
Macro names are given in uppercase, except for a prefix that indicates where they are defined (e.g: 'pdTRUE' because the macro is defined in 'projdefs.h', whose abbreviation is 'pd', or 'taskENTER_CRITICAL()' because the macro is defined in 'task.h').
Arduino IDE maps 'digital pin x' to a port and pin combinations in different platforms. On the ATmega328P digital pin x maps to pin PD3, om the ESP32 to 'GPIO x' (GPIO stands for 'General Purpose Input/Output').
The ESP32 has hardware limitations for GPIO (e.g: GPIO 34 to 39 inclusive can only be used for input).
SPI (Serial Peripheral Interface) is frequently used within ESP32: ESP32's SPI Flash equals to a common computer's hard disk (permanent memory).
ESP32's SRAM (Serial Random Access Memory) equals to a common computer's RAM.
GPIO 6 to 11 are connected to the integrated SPI Flash.
The ESP32 device uses 3.3 volt GPIO ports and none are 5 volts tolerant. Inputs should never be subjected to above 3.3 + 0.6 volts (3.9 volts represent ESP32's physical limit).
