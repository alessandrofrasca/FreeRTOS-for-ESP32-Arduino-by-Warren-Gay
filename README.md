This repository documents my journey reading and analyzing the book *FreeRTOS for ESP32-Arduino: Practical Multitasking Fundamentals* by Warren Gay.
I wanted to explore this topic in depth to begin developing efficient (and robotics-oriented) projects using the ESP32.
I began this study in August 2026, during my summer break, prior to the start of my second year of Computer Engineering.
Given my lack of experience, the repository may contain errors in the code or comments; please let me know if you find any.
Here is an explanation of the purpose of the following subfolders:
- 'notes': contains all the notes I took chapter by chapter, as well as code examples;
- 'errata': contains significant errors I identified in the code provided in the book.
